# Movie Library

**Автор:** Карпова Карина Акназаровна

## Описание
Приложение для хранения личной кинотеки. Позволяет добавлять фильмы, фильтровать их по жанру и году, а также сохранять данные в формате JSON.

## Запуск
1. Установите Python 3.x.
2. Запустите: python main.py

## Примеры использования
- Добавьте фильм через форму.
- Используйте фильтры для поиска по жанру/году.
- Данные сохраняются в файл movies.json.
